# EmpireConnections v0.1.1

- Honors the signed EmpireInsights SSO payload's requested `view` value.
- Redirects an authenticated administrator to `/?view=advisor` when Advisor View is requested.
- Keeps Admin View available through the existing Admin View / Advisor View switch.
- Preserves advisor extensions, phone registration, inbound queues, campaigns, layouts, leads, and reporting data.
