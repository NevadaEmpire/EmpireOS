# EmpireConnections v0.1.4

- Added a mandatory mapping-verification step before any lead-list import.
- Added persistent custom lead fields that administrators can create during mapping.
- Shows every CSV column, sample value, selected destination, and required/optional status before confirmation.
- Rejects duplicate destination mappings and duplicate CSV headings before import.
- Enforces required mapped fields and prevents unverified server-side imports.
